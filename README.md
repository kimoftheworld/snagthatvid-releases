# SnagThatVid

Download videos and music from YouTube, TikTok, Facebook, Instagram and many more sites — with a
built-in library, AI transcripts and automatic downloads.

## Download

Get the latest installer from the **[Releases page](https://github.com/kimoftheworld/snagthatvid-releases/releases/latest)**
(`SnagThatVid-Setup-<version>.exe`, Windows 10 and 11).

SnagThatVid updates itself: when a new version is out, it downloads in the background and asks you
to restart.
